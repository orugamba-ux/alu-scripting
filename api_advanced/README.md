# api_advanced

The Reddit API scripts for this project.

- `0-subs.py` - number of subscribers of a subreddit
- `1-top_ten.py` - titles of the first 10 hot posts
- `2-recurse.py` - titles of all hot posts, done recursively
- `3-count.py` - counts given keywords in those titles

Each file has one function in it, so you call it from your own main script.
